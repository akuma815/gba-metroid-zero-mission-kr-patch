  MetroidZeroMission_KR_20260824.xdelta   ROM 패치
  apply.cmd                               적용 도우미
  apply.ps1                               적용 스크립트

원본 또는 패치 완료 ROM은 배포물에 포함되지 않습니다.


■ 1. 적용 방법

원본 .gba 파일을 apply.cmd 위로 끌어다 놓거나 다음처럼 실행합니다.

  apply.cmd "Metroid - Zero Mission (Japan).gba"

출력은 원본 옆의 `<원본 이름>_KR.gba`입니다.

원본과 결과물 검증값:

  원본:    8,388,608 바이트 (No-Intro "Metroid - Zero Mission (Japan)")
           D087CA6E2D1808109A579C2283E944D81C8426D37DE564F99EA9273087C2172A
  패치 후: 8,388,608 바이트
           944D2EEE3AFA7C407624E4C810F48C1ED69E310B5E1C9C58F2AEE8091AA97D57

일본판 전용입니다. 미국판·유럽판에는 적용되지 않습니다.
파일 크기는 원본과 같습니다. 번역문이 원문보다 작아 확장 없이 들어갔습니다.


■ 2. 번역 범위

  · 런타임 메시지 127건 전량
    인트로 독백, 제로 슈트 구간 서술, 아이템 획득 설명, 튜토리얼,
    지령·통신 메시지, 파일 선택·옵션·난이도·삭제 확인 등 UI 문구
  · 타이틀 로고 `METROID / ZERO MISSION` → `메트로이드 / 제로 미션`
  · 파일 선택 [데이터복사] [데이터삭제] [옵션], 세이브 요약(난이도·지역명)
  · 옵션 화면 사운드 / 사운드 테스트 / 타임 어택 기록 / 갤러리 /
    퓨전 데이터 읽기 / 퓨전 갤러리 / 오리지널 메트로이드
  · 맵 화면 슬립 / 상태 / 구역 이동, 지역명 판, 지도 위 지역명 7종
  · 스테이터스 화면 항목 이름 25종(빔·미사일·슈트·능력)
  · 지역 진입 배너, 후반 아이템 이름(플라즈마·스페이스점프·그래비티)
  · 게임 오버 화면, 데이터 삭제 확인 화면
  · 통신(링크 케이블) 완료·실패 화면

언어 설정이 한자든 히라가나든 어느 쪽이어도 한국어로 나옵니다.


■ 3. 원문을 유지한 것

  · 엔딩 스태프롤 — 직함(영문)과 제작진 이름(로마자), 저작권 문구.
    제작진 크레딧은 원저작자 표기이고 이름이 로마자입니다.
  · 인트로 상단 영어 문구(EXTERMINATE ALL METROID ...) — 연출 요소
  · 파일 선택 화면의 SAMUS DATA / COPY / ERASE / OPTIONS —
    원본도 영문과 일본어를 나란히 병기합니다
  · 스테이터스 화면의 미확인 아이템 이름 — 원본이 깨진 글자입니다


■ 4. 알려진 한계

  (1) 패치 전 세이브를 이어서 하면 일부 지도 지역명의 마지막 글자가
      빠져 보일 수 있습니다.

      게임은 지도 칸마다 "보였는지"를 세이브에 기록합니다. 한국어 이름이
      원문보다 길어진 `크레테리아`와 `크레이드`는 칸을 하나 더 쓰는데,
      패치 전에 이미 발견해 둔 구역은 옛 칸 수가 세이브에 굳어 있습니다.
      새로 시작하면 정상입니다.

  (2) 통신(링크 케이블) 화면은 실기 확인을 하지 못했습니다.
      링크 케이블 또는 메트로이드 퓨전 카트리지가 필요해 에뮬레이터
      단독으로는 도달할 수 없습니다. 데이터 검증만 마쳤습니다.

  (3) 에뮬레이터에 따라 세이브 파일이 ROM 파일명에 묶입니다
      (예: Mesen은 Saves 폴더에 <ROM 파일명>.sav). ROM 파일명을 바꾸면
      기존 세이브를 못 읽으니, 이름을 바꿀 때는 세이브 파일도 같은
      이름으로 복사해 주세요.


■ 5. 실행 환경

패치 후 ROM은 원본과 같은 8MiB 게임보이 어드밴스 카트리지 구성입니다.
매퍼·세이브 방식(SRAM)을 바꾸지 않았으므로 원본이 돌아가는 곳이면
그대로 동작합니다. Mesen 2에서 검증했습니다.


■ 6. 제거

원본 .gba 파일을 그대로 다시 사용하면 됩니다. 패치는 원본을 수정하지
않고 별도 파일을 만듭니다.


■ 7. 주의·저작권

패치 적용이 끝난 .gba 파일을 배포하지 마세요. xdelta 파일만 공유할 수
있습니다. SHA256.txt로 배포 파일의 무결성을 확인할 수 있습니다.

이 패치는 비공식 팬 번역이며 닌텐도와 무관합니다. 게임의 저작권은
Nintendo에 있습니다.
